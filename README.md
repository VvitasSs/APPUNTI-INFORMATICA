# APPUNTI-INFORMATICA
## GIT
### Inizializzazione
Creazione di un *repository*
- `git init`
### Abilitare il tracciamento
- `git add`
### Visualizzare lo stato
- `git status`
### Visualizzare le differenze
- `git diff`
### Consegnare il lavoro
- `git commit`
### Condivisione
- `git push`
- `git pull`
- `git merge`
